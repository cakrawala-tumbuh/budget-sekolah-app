# Memulai

## Masuk (Login)

1. Buka aplikasi Budget Sekolah di peramban (browser) Anda.
2. Pada halaman **Masuk**, isi:
   - **Username** — nama pengguna yang diberikan administrator.
   - **Password** — kata sandi Anda. Gunakan ikon mata untuk menampilkan/menyembunyikan.
3. Klik tombol **Masuk**.

Jika kredensial salah, akan muncul pesan "Login gagal. Coba lagi." Hubungi administrator
bila Anda lupa kata sandi atau akun belum aktif.

!!! info "Belum punya akun?"
    Akun dibuat oleh **Administrator** melalui menu **Pengguna**. Lihat
    [Administrasi](admin.md#manajemen-pengguna).

## Mengenal antarmuka

Setelah masuk, Anda akan melihat:

- **Sidebar (menu samping)** — navigasi utama. Isinya menyesuaikan peran Anda.
- **Dashboard** — kartu pintasan ke fitur utama dan sapaan sesuai peran Anda.
- **Info pengguna** — nama dan peran (Administrator / Organisasi) di bagian bawah
  sidebar, beserta tombol **Keluar**.

### Menu untuk Administrator

| Menu | Fungsi |
|------|--------|
| **Dashboard** | Ringkasan dan pintasan |
| **Organisasi** | Kelola struktur Pusat / Cabang / Unit |
| **Simulasi** | Simulasi anggaran lintas organisasi |
| **Pengguna** | Kelola akun & hak akses |
| **Kategori Pendapatan** | Master data pendapatan |
| **Kategori Biaya** | Master data biaya |
| **Kategori Investasi** | Master data investasi |

### Menu untuk Pengguna Organisasi

| Menu | Fungsi |
|------|--------|
| **Dashboard** | Ringkasan dan pintasan |
| **Organisasi** | Lihat organisasi Anda sendiri beserta organisasi di bawahnya (berjenjang) |
| **Simulasi** | Langsung ke simulasi organisasi Anda |

Pengguna Organisasi hanya dapat mengakses data milik organisasinya sendiri dan
seluruh organisasi yang dinaunginya secara berjenjang. Menu **Organisasi** bersifat
**lihat saja** — tidak tersedia tombol untuk menambah, mengubah, atau menghapus
organisasi.

## Navigasi dasar

- Klik **logo aplikasi** di kiri atas untuk kembali ke Dashboard.
- Di perangkat seluler (mobile), gunakan ikon menu untuk membuka/menutup sidebar.
- Tombol **panah kembali** (←) di setiap halaman detail membawa Anda ke daftar sebelumnya.

## Keluar (Logout)

Klik **Keluar** di bagian bawah sidebar. Anda akan diarahkan kembali ke halaman Masuk.
