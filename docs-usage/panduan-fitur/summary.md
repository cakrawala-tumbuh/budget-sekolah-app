# Summary Anggaran

Halaman **Summary Anggaran** menampilkan ringkasan anggaran organisasi dalam format laporan terstruktur yang mencakup pendapatan, biaya operasional, biaya non-operasional, dan depresiasi. Halaman ini dirancang untuk memudahkan cetak/ekspor.

## Membuka Summary Anggaran

1. Buka halaman detail organisasi.
2. Klik tombol **Summary** di bagian atas halaman.

## Tampilan Halaman

Summary ditampilkan dalam format tabel dengan dua kolom nilai:

| Kolom | Keterangan |
|---|---|
| **Kas** | Nilai yang mempengaruhi arus kas nyata |
| **Akrual** | Nilai akrual (termasuk beban non-kas seperti depresiasi) |

Baris-baris dikelompokkan berdasarkan kelompok akun:

- **Pendapatan Operasional** — UP, US, dan pendapatan operasional lainnya
- **Pendapatan Non-Operasional** — Pendapatan di luar operasional utama
- **Biaya Operasional** — Dikelompokkan per kode akun (Biaya Gaji, Biaya Operasional Sekolah, dsb.)
- **Biaya Non-Operasional** — Biaya di luar kegiatan utama
- **Depresiasi** — Beban penyusutan aset tetap

## Mencetak Summary

Klik tombol **Cetak** (ikon printer) di pojok kanan atas untuk membuka dialog cetak browser. Halaman dirancang agar tampil rapi saat dicetak.

!!! tip "Simpan sebagai PDF"
    Di dialog cetak browser, pilih **Save as PDF** (atau **Simpan sebagai PDF**) sebagai printer untuk menyimpan summary dalam format PDF.
