# Cara Memulai

Panduan singkat untuk pengguna baru agar dapat langsung menggunakan aplikasi Budget YPII.

## Mengakses Aplikasi

Buka browser dan kunjungi URL aplikasi yang diberikan oleh administrator. Aplikasi dapat diakses dari komputer maupun perangkat mobile.

## Login

1. Di halaman login, masukkan **Username** dan **Password** yang telah diberikan oleh administrator.
2. Klik tombol **Masuk**.
3. Jika login berhasil, Anda akan diarahkan ke halaman daftar organisasi.

!!! warning "Lupa Password?"
    Hubungi administrator sistem untuk mereset password Anda. Password baru akan diberikan secara langsung oleh admin.

## Orientasi Antarmuka

Setelah login, Anda akan melihat:

- **Sidebar kiri** — Menu navigasi utama (pada layar lebar). Di layar kecil, sidebar dapat dibuka lewat ikon menu di pojok kiri atas.
- **Halaman Organisasi** — Daftar semua organisasi yang dapat Anda akses.

### Peran Pengguna

| Peran | Akses |
|---|---|
| **Admin** | Semua organisasi, panel admin (kategori biaya, kategori investasi, manajemen pengguna) |
| **Organisasi** | Organisasi sendiri beserta unit/cabang di bawahnya |

## Langkah Pertama

Alur kerja umum untuk pengguna organisasi:

1. **Buka organisasi Anda** — Klik kartu organisasi di halaman Organisasi.
2. **Isi Asumsi Siswa** *(khusus UNIT)* — Masukkan data jumlah siswa per kelas dan siswa baru.
3. **Input biaya** — Masukkan entri biaya operasional, biaya non-operasional, investasi, dan depresiasi aset lama.
4. **Input pendapatan** — Masukkan entri pendapatan non-UP/US.
5. **Lihat Simulasi** — Klik tombol **Lihat Simulasi** untuk melihat hasil kalkulasi tarif UP/US dan proyeksi anggaran.

Untuk panduan lengkap setiap langkah, lihat bagian [Panduan Fitur](../panduan-fitur/index.md).
