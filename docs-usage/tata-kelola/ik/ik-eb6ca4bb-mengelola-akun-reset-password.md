# IK Mengelola Akun & Reset Password Organisasi

Instruksi Kerja Mengelola Akun & Reset Password Organisasi ini memandu Admin meninjau daftar akun
pengguna dan mereset password akun organisasi pada halaman Pengguna di Panel Admin aplikasi
Budget YPII. Password baru hasil reset hanya ditampilkan satu kali di layar dan harus segera disalin.

## Tujuan

Instruksi Kerja Mengelola Akun & Reset Password Organisasi bertujuan memulihkan akses pengguna
organisasi yang lupa password secara aman, sekaligus memastikan Admin memiliki gambaran akun pengguna
yang terdaftar.

## Prasyarat

Sebelum menjalankan Instruksi Kerja Mengelola Akun & Reset Password Organisasi, pelaksana telah login
sebagai pengguna dengan peran Admin, dan identitas organisasi yang meminta reset telah diverifikasi.

## Peralatan / Akses yang Dibutuhkan

Instruksi Kerja Mengelola Akun & Reset Password Organisasi dijalankan pada aplikasi Budget YPII,
halaman **Pengguna** di Panel Admin (`/admin/users`), oleh pelaksana dengan peran Admin.

## Instruksi

### 1. Membuka halaman Pengguna

1. Klik bagian **Administrasi** di sidebar (menu ini hanya tampil bagi Admin).
1. Klik submenu **Pengguna**.

Halaman Pengguna menampilkan daftar semua akun yang terdaftar, baik akun Admin maupun akun organisasi.

### 2. Mereset password organisasi

1. Temukan baris organisasi yang bersangkutan pada daftar.
1. Klik tombol **Reset Password** (ikon kunci).
1. Konfirmasi pada dialog yang muncul.
1. Salin password baru yang ditampilkan di layar, lalu simpan di tempat aman **sebelum menutup dialog**.
1. Tutup dialog.
1. Berikan password baru kepada pengguna organisasi tersebut secara langsung.

> Setelah dialog reset password ditutup, password baru tidak dapat dilihat lagi dari sistem. Pastikan
> Anda telah menyalinnya sebelum menutup dialog. {.is-danger}

## Hasil yang Diharapkan

Setelah Instruksi Kerja Mengelola Akun & Reset Password Organisasi selesai, akun organisasi memiliki
password baru yang telah disalin Admin dan diserahkan kepada pengguna, sehingga pengguna dapat login
kembali.

## Troubleshooting

- **Dialog sudah tertutup sebelum password disalin** — password tidak dapat ditampilkan lagi; ulangi
  proses reset untuk menghasilkan password baru, lalu salin sebelum menutup dialog.
- **Tombol Reset Password tidak muncul** — pastikan baris yang dipilih adalah akun organisasi, bukan
  akun Admin, dan Anda login dengan peran Admin.
