# Otomasi Sistem (OTS)

Kumpulan dokumentasi Otomasi Sistem tata kelola RAB yayasan pendidikan. Tiap OTS mendokumentasikan
alur yang dijalankan **sistem secara otomatis** (bukan langkah manual manusia): pemicu, alur, rumus,
konfigurasi, dan penanganan error. OTS dirujuk dari SOP/IK pada bagian yang berjalan otomatis.
